# Site profissional: Psicóloga Kettily Formiga

Site institucional de uma psicóloga clínica, feito com HTML, CSS e JavaScript puro. A página reúne a apresentação da profissional, os serviços, depoimentos, perguntas frequentes e contato direto pelo WhatsApp.

## Seções

- **Início:** apresentação com chamada para agendamento
- **Sobre:** trajetória profissional
- **Serviços:** como a psicóloga pode ajudar
- **Depoimentos:** carrossel com troca automática
- **FAQ:** perguntas frequentes em formato sanfona (abre e fecha)
- **Contato:** formulário e botões que abrem conversa no WhatsApp

## Destaques técnicos

- JavaScript sem bibliotecas, com configurações centralizadas num objeto `CONFIG`
- Menu responsivo para celular e rolagem suave entre as seções
- Debounce e throttle nos eventos de rolagem, para a página não ficar lenta
- Tela de carregamento e animações de entrada
- Layout responsivo com media queries

## Tecnologias

- HTML5
- CSS3
- JavaScript (ES6)

## Como abrir

Não precisa instalar nada: baixe o repositório e abra o `index.html` no navegador.

Para usar em produção, troque o número de WhatsApp e o e-mail no objeto `CONFIG`, no início do `script.js`.
